### 2.2 架构确认：正式版 = HY4-VL 形态（本地商发分支推断被证实）

模型卡（HF `cardData.architectures`）与 README 一致：**`HYV4VLForConditionalGeneration`**——与本地商发分支 10 月注册的架构名（`vllm_ascend/patch/hy4_vl/`）**逐字一致**，上轮"Hy4 正式版视觉能力载体是 Hy4-VL 形态"的推断**被证实**。

正式版与 preview 的架构差异（README 规格表）：

| 项 | Hy4 preview（8-28） | **Hy4 正式版** |
|---|---|---|
| 模态 | 纯文本 | **text + image + video** |
| 视觉编码器 | 无 | **ViT 1.23B**：40 层、hidden 1,536、FFN 6,144、16 heads、patch 16、位置嵌入 128×128、2×2 merge |
| 投机解码 | 原生 MTP 层（10B/0.7B） | **DFly2 drafter（5 层，3.3B）** |
| 激活参数 | 49B | **Text 49B + Vision 1.23B** |
| 其余 | 相同：770B 总参、78 层（1 dense + 77 MoE）、hidden 6,144、Gated DSA + IndexCache（indexer 32×128、top-k 2,048）、256+1 专家 top-8、iHC 4 流、1M 上下文、词表 120,832 | |

> ⚠️ 注意：本地商发分支验证报告中的视觉塔规格（27 层 / hidden 1,152）**不等于**正式版的 ViT（40 层 / 1,536）——更接近 flash 的视觉塔（27 层 / 1,152，SigLIP2-So400m 改版）。商发分支 10 月适配的是当时内部版本的配置，与最终开源权重的对齐情况需实机验证。

### 2.3 DFly2：第三条投机解码路线

- 机制：5 层 drafter，**每层复用对应 DSA 层的 KV cache（KV Share）与 indexer 选出的 top-2,048 位置（Index Share）**；用 AngelSpec 训练。
- 三优势（README 原文）：① **常数成本**——每个 draft token 至多看 ~2K keys，不随上下文增长；② **零额外 KV 内存**——drafter 不单独维护 KV cache；③ **PD 分离就绪**——不参与 prefill，P→D 传输只多一个末层 hidden state。
- 部署：vLLM `--speculative-config '{"num_speculative_tokens":5,"method":"dfly"}'`；SGLang `--speculative-algorithm DFLY`（两边均已内置）。
- 定位：与原生 MTP（preview/Hy3）、DSpine（腾讯其他团队）并列的**第三条投机路线**，专门为稀疏注意力模型设计（draft 直接吃 indexer 的选择结果）。

## 三、⭐ Hy4 flash —— 上线两天即开源 + 三项新架构

### 3.1 时间线与规格

**11-16 上线（API/产品）→ 11-18 开源**（`Hy4-flash` / `-FP8` / `-base`，GitHub/HF/ModelScope/AtomGit 四平台）——对比 Hy4 的"产品先行 ~12 天"，flash 恢复"两天开源"节奏。媒体（腾讯云社区）称 11-18 当日"上线首日 Token 调用量突破 50 万亿，创混元系列首日调用新高"、OpenRouter LLM 日榜登顶。

| 项 | 值（README 规格表） |
|---|---|
| 总参 | **224B**（= backbone 155.5B + **Engram 63.5B** + ViT 0.43B + DFly2 0.85B） |
| 激活 | **Text 11.3B + Vision 0.43B**（官方口径"12B 激活"） |
| 层数 | 42（1 dense + 41 MoE）、hidden 3,072、词表 120,832、iHC 4 流 |
| 上下文 | 1M（1,048,576） |
| 注意力 | **混合布局：2 × Sparse → 10 × (3 × SWA → Sparse)**——12 稀疏层 / 30 SWA 层（1:3）；MLA；稀疏层组级选择 ≤2,048 token，SWA 窗 512；Interleaved MRoPE |
| MoE | **LatentMoE**：512 路由专家取 16 + 1 共享，潜空间 1,536，专家 FFN 1,536 |
| **Engram** | **N-gram embedding**：bigram + trigram，多头哈希（每阶 8 heads × 10.3M 词表/head，每阶 768 维），注入第 1/11/21/31 层；参数表 63.4B |
| 视觉 | ViT 0.43B：**27 层、hidden 1,152**（SigLIP2-So400m-Patch16-Res512 改版）、16 heads、patch 16、pos 128×128、2×2 merge——**与本地商发分支 10 月验证的视觉塔规格一致** |
| 投机 | DFly2 0.85B（5 层，同 KV Share + Index Share 机制，索引为压缩 indexer 的 ≤2,048 选择） |

### 3.2 效率主张（README"Practicality and Cost Efficiency"）

- **KV cache 仅 Hy3 的 1/24、Hy4 的 1/6**（混合注意力 + LatentMoE 的直接收益）；
- 后训练：**从 Hy4 自蒸馏**建立通用智能 + RL 将平均端到端输出 token 削减 **50%**；
- 推理：megakernel + **4-bit 量化** + DFly2 → **解码超 150 tokens/s**；
- 新评测口径：**WorkIndex**（8 个内部工作集：PPT 制作/修改/人机双写、Markdown 人机双写、文档编辑、表格修复、音视频处理、视觉理解）+ 7 个公开 Agent 集（DeepSWE、ProgramBench、Terminal-Bench 4.0、APEX-Agents、AutomationBench、HLE、OSWorld 2.1）；WorkIndex **42.1 vs Hy4 preview 39.7**——**性能略超 770B 的 preview**；
- 单任务成本：preview 的 **1/13**、Hy4 的 **1/20**、DeepSeek-V4.1-Flash-1017 的 **1/8**（Max 档峰时价）；
- 85 位 WorkBuddy 内部用户盲测（27 类 259 任务）：满意度接近 **Claude Haiku 5.5**，成本最低、时长最短。

### 3.3 商业与定位

- 定价：输入 **0.5 元** / 输出 **2 元** / 缓存命中 0.02 元（每百万 tokens；约 $0.070/$0.281/$0.003）；
- 上线面：TokenHub、WorkBuddy、元宝、企业微信、QQ、ima、Marvis；OpenRouter"即将接入"；11-30 前 WorkBuddy 免费、TokenHub 5 折；
- 官方分工建议：日常任务（深度搜索/文档/PPT/简单前端/Computer Use）用 flash；长程软件工程等用 Hy4；
- ⚠️ License：flash 仓库同样为 Tencent Hy License（同 Section 10 MaaS 条款，引用前需逐仓核对 LICENSE 文件）。

## 六、结论

本窗口一句话：**混元把 11-04 的开源承诺全部兑现，并用 flash 把开源节奏拉回"两天"**。技术上，DFly2（KV+Index 共享投机）替代 MTP 成为稀疏注意力旗舰的标准配置；flash 以 LatentMoE + Engram + 1:3 混合注意力三项新架构把"日常任务成本"压到 Hy4 的 1/20（WorkIndex 性能还略超 preview）——**"旗舰保上限、flash 保日常"的双模型结构成型**。必须记录的暗线：**正式版权重的 License 从 Apache-2.0 收窄为带 MaaS 条款的 Tencent Hy License**（$50M 营收/1 亿 MAU 门槛）——"开源"的开放度在商业维度收紧，这是与"全部兑现"并行的另一面。昇腾侧：权重已可拉取、官方指南已合入 vLLM-Ascend，进入实机验证窗口（P0）；本地商发分支的视觉塔规格与正式版 ViT 存在差异，重同步时需重点核对。
