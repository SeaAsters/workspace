## 一、总览

窗口内组织仓库 95 → **99**（+2 新：`Hy4-flash`、`MovieRoll`；+2 补录：`Hy4`（10-28 建仓、11 月中转公开）、`ORAV-Bench`）。**本窗口主题只有一个：Hy 系权重全部兑现开源**——

- ⭐ **Hy4 正式版权重开源**：`Hy4`（BF16）+ `Hy4-FP8` + **`Hy4-base`（预训练底座）** 三件套上 HF，另有 `AngelSlim/Hy4-GGUF`；**架构名 `HYV4VLForConditionalGeneration` 与本地商发分支完全一致**（上轮推断被证实）；**License 从 Apache-2.0 改为 Tencent Hy License（含 MaaS 商业条款）**；System Card 已发布；

- HF 侧同时爆量上架 **WeMM-Video 家族**（2B/4B/9B/35BA3B × 5 档量化含 NVFP4，腾讯其他团队）20+ 仓库；
- UniRL 新算法 AROPD、FlashTopK 新增 SM100 支持、Hy-Memory 2.0.15。

## 三、⭐ Hy4 flash —— 上线两天即开源 + 三项新架构

| 项 | 事实 |
|---|---|
| 时间线 | **11-16 上线**（API/产品）→ **11-18 开源**（`Hy4-flash` + `-FP8` + `-base` 三件套，GitHub/HF/ModelScope/AtomGit）——对比 Hy4 的"产品先行 12 天"，flash 恢复了"两天开源"节奏 |
| 规格 | **224B 总参 / 12B 激活**（backbone 155.5B + **Engram 63.5B** + ViT 0.43B + DFly2 0.85B）；42 层；**Text 11.3B + Vision 0.43B** 每 token 激活；1M 上下文 |
| **新架构 ①** | **混合注意力**：Sparse（IndexPool）与 SWA 按 **1:3 交错**（12 稀疏层 / 30 SWA 层，SWA 窗 512 token） |
| **新架构 ②** | **LatentMoE**：路由专家在 1,536 维潜空间工作，512 专家取 16 |
| **新架构 ③** | **Engram N-gram embedding**：bigram+trigram 多头哈希检索（8 heads × 10.3M 词表/head），注入第 1/11/21/31 层——64B 参数表 |
| 效率 | **KV cache 仅 Hy3 的 1/24、Hy4 的 1/6**；RL 削减端到端输出 token 50%；megakernel + 4-bit 量化 + DFly2 → **解码 >150 tokens/s** |
| 评测 | WorkIndex（8 个内部工作集）**42.1 vs Hy4 preview 的 39.7**——性能略超 preview；单任务成本 = preview 的 **1/13**、Hy4 的 **1/20**、DeepSeek-V4.1-Flash 的 1/8；85 位 WorkBuddy 用户盲测满意度接近 Claude Haiku 5.5 |
| 商业 | 定价 0.5 元/百万输入、2 元/百万输出、缓存 0.02 元（约 $0.070/$0.281/$0.003）；媒体称首日 Token 调用破 **50 万亿**（混元首日新高）、OpenRouter 日榜登顶；11-30 前 WorkBuddy 免费、TokenHub 5 折 |
| 定位分工 | 官方推荐：日常任务（深度搜索/文档/PPT/简单前端/Computer Use）用 flash，长程软件工程等复杂任务用 Hy4 |

## 六、结论

本窗口就一件事：**混元把 11-04 的"近期开源"承诺全部兑现**——Hy4 正式版三件套（含罕见的预训练 base）+ System Card 落地，且 flash 以"上线两天即开源"的节奏回归快速兑现模式；架构上 DFly2（KV+Index 共享投机）替代 MTP、flash 首创 LatentMoE/Engram/1:3 混合注意力三项省成本架构。**必须注意的暗线是 License 变化**：正式版从 Apache-2.0 转为带 MaaS 条款的 Tencent Hy License（$50M 营收/1 亿 MAU 门槛）——"开源"的开放度在收窄，商用部署前必读条款。昇腾侧动作：权重已可拉取，进入实机验证窗口（P0）。
