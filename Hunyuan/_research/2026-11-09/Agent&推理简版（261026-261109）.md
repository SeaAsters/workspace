## 三、⭐ FlashTopK / HyScale —— 稀疏注意力内核全栈开源

- **内核**（Apache-2.0，11-06 v1）：快速/**精确**/**确定性**的 fused top-k，full prefill 比 dense scoring + FlashInfer top-k 快 **1.7-3.3×**（trained indexer）；Hopper（H800/H20/H100/H200），FP8/BF16，topk≤4096；全程单流零回读、可入 CUDA graph；确定性到"-0.0 平 +0.0、平局取最小 index"。
- **支持矩阵点名 Hy4-preview**（indexer 32 heads×128）与 GLM-5.1/5.2/5.3/5.3-Flash（同形状）、DSA 类模型——与 Hy4 README 的 Gated DSA + IndexCache + indexer top-k 2048 **逐字互证**。
- **HyScale 训练系统**（arXiv 2610.32057）：FlashTopK + selection replay，GLM-5.1 1M-token 训练 **2.07×** vs Megatron-LM（512×H20）；DeepSeek-V4-Flash CSA 层 2.01×、Qwen3.8-Flash-Next QSA 层 1.57×。
- **Roadmap**：block-level LSA（CSA/QSA）、paged KV cache、64-head indexer——指向 DeepSeek-V3.2/V4 与 Qwen 变体，**生态标准卡位**。

## 五、本地 vllm-ascend-hy4（商发分支概览）

本地商发分支（`hy4-v0.30.0`，基于上游 v0.30.0rc1 + 127 commits，其中 11 个 HY4 相关）已完成 **HY4 系列的昇腾适配与端到端验证**，且**时间早于 Hy4 正式版发布约两周**：

- 覆盖文本（MXFP8 权重加载与量化语义对齐）与**多模态（Hy4-VL 图像/视频）**两条链路，验证环境为 8 卡 Atlas 950DT；
- 部署形态覆盖：eager → 异步调度 → 图模式（decode 捕获）→ MTP 投机解码 → **PD 分离** → 单实例快速路径，均有真实请求级验证记录；附带 GPQA 与多模态冒烟验证工具链；
- iHC 等混元定制算子有昇腾融合实现（与 SGLang 上游实现同源）；官方 NPU 侧配套镜像与教程同期存在（当前仅 Atlas A3、W8A8 权重、源码安装暂不支持）。

**读法**：混元旗舰的"发布日 = 昇腾 day0"已是制度化动作——NPU 侧适配在正式版发布前就绪，而非社区后补。正式版权重开源后需重新同步分支，核对视觉塔/MTP 是否与 preview 一致（本地分支的细节取证见 08 号报告 §6，此处不展开）。

## 七、结论

本窗口最有参考价值的就两件事——**Hy4 正式版**（把发布模式从"开源日"切到"产品日"，agent 能力首次进旗舰，权重开源是下一个观察点）和 **FlashTopK/HyScale**（稀疏注意力从模型架构选择变成"训练系统→内核"的全栈开源资产，且同时服务 GLM/DeepSeek/Qwen 变体，是生态标准卡位）；其余（Hy-SimulMT、双基准、Hy-Memory 迭代）为背景增量。昇腾侧动作：本地商发分支已为 Hy4 day0 备好底座，权重开源后进入核对窗口；FlashTopK 内核思路与 Hy-SimulMT 负载形态按 P1 跟踪。
