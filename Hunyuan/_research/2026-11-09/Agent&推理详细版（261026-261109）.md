## 三、⭐ FlashTopK / HyScale —— 稀疏注意力从架构到内核的全栈开源

### 3.1 内核（Apache-2.0，11-06 v1）

- 快速、**精确**（真 top-k，漏采行 GPU 重打分）、**确定性**（平局取最小 index，-0.0 平 +0.0）、**CP 兼容**（阈值来自自身窗口，无需跨 rank 选择）的 fused top-k 选择内核，训练与推理通用。
- 性能：full prefill 比 dense scoring + FlashInfer top-k（DeepGEMM/cuDNN scoring）快 **1.7-3.3×**（trained indexer）、**1.2-2.0×**（untrained）；H800 实测。
- 硬件/操作数：NVIDIA Hopper SM90（H800/H20/H100/H200）；FP8（带 per-key scale）或 BF16；topk ≤ 4096。
- 工程：单流零回读、可入 CUDA graph；`torch.compile` custom op；`plan()` 预编译全部 CuTe 内核变体；workspace 可预算；健康状态可观测（溢出/不足/重打分行数）。

### 3.2 HyScale 训练系统（arXiv 2610.32057，v1 10-23 / v3 11-04）

核心洞察："**selection 的输出不是 activation，而是一组 indices**"——FlashTopK（无 score table 的 on-the-fly 精确 top-k）+ selection replay（recomputation 复用前向选择）。端到端：**GLM-5.1 在 1M-token 序列训练 2.07×**（vs Megatron-LM，512×H20）；DeepSeek-V4-Flash CSA 层 **2.01×**、Qwen3.8-Flash-Next QSA 层 **1.57×**（1M tokens，32×H800）。

### 3.3 与 Hy4 的互证及生态含义

- 支持矩阵点名 **Hy4-preview（indexer 32 heads×128）** 与 GLM-5.x（同形状）——与 Hy4-preview README 的 Gated DSA + IndexCache（Indexer 32/128、top-k 2048）**逐字吻合**：旗舰长上下文的底层选择机制首次内核级开源可复算。
- **Roadmap**：block-level LSA（DeepSeek-V4 CSA、Qwen3.8-Flash-Next QSA）、paged KV cache、64-head indexer（DeepSeek-V3.2）——**同时服务多家模型变体**，是把 DSA 做成跨厂商公共设施的标准卡位。
- 稀疏注意力仓库线三代：HiLS-Attention（库）→ flex-block-attn（块稀疏 CUDA）→ **FlashTopK（fuse+精确+确定性内核）**。

## 四、Agent 侧其他进展

### 4.1 HyperLogic（10-28 公开，Apache-2.0，arXiv 2605.19597 v2）

- **方法**：先写题、后导答案——本科生写中文种子题 → 四角色 agent 加固但禁止解题 → 两个模型家族独立形式化 → **求解器执行导出答案**，双编码一致才发布。
- **结构**：Seed 228 / Base 195（922 子题）/ Hard 100，只公开 **30%**（SHA-256 commitment，70% 私有防污染）。
- **关键结果**（全量基准）：Base 拉开 33 分（44.6~77.6%）；**Hard 直答全部 <16%**，code sandbox +16.7~40.1 分但最高 55.7%；logic modeling library 加分不稳定（−6.0~+10.6）；**7 个前沿模型里 6 个写 plain Python 枚举而不用 solver**——工具可用性悖论的一手证据。
- ⚠️ 7 个参评模型里没有混元自家模型。

### 4.2 AppCIF-Bench（11-05，NeurIPS 2026，代码 Apache-2.0 / 数据 CC-BY-NC-4.0）

- **首个应用级 CIF 基准**：两轴分层（Horizon Length × Logical Depth）；**Prompt-as-Environment**——L4 系统提示约 14k 词 + 6 个可执行 Code Simulation Engines（约 3.5k 行 Python/个，纯标准库）产生 ground truth。
- 规模：466 样本 / 3,017 atomic rubrics（中英同构）；SSR + HSR 双指标，judge 为 Doubao（v1.1 用 Seed-2.0-lite）。
- **12 个 LLM 的 HSR 仅 1.1%~45.9%**：GPT-5.4-xhigh 45.9% 断层第一；L4 级除 GPT 外全部 ≤2.2%。v1.1 修正 1,084 条 rubric，与论文数字不可比。

### 4.3 Hy-Memory：产品化高频迭代 + 官网生产数据

- **迭代**：窗口内 295 commits；SDK **2.0.5 → 2.0.14**（10-27~11-04，9 个版本；新增 rerank 旁路、`statuses` 过滤等）；MemHub **1.0.5**（10-28）/ **1.0.6**（11-06 tag；Unreleased 已预告 capture hook 不再直写 DB、hook 与 live-sync 去重两架构级改动）。stars +730，**有真实迭代支撑**（与 Prism 的纯传播热度形成对照）。
- **官网**（memory.hunyuan.tencent.com，11-09 抓取）三条新证据：
  1. 模型层**六指标明细**含 **LongMemEval 77.7**（Opus5 78.87 更高——"超 Opus5"仅对六项均值成立）；上轮"LongMemEval 无证据"部分解除；
  2. MemHub 宿主**官方确认 10 种**：WorkBuddy / Cursor / Codex / Claude Code / OpenCode / OpenClaw / Qwen Code / Pi / Hermes / DeepSeek Harness；

## 五、推理侧其他进展

### 5.1 Hy-SimulMT（补录，10-26 12:53 公开）

- **定位**：实时同传大模型，中英双向语音到语音 + 实时音色克隆；30B-A3B（hy_v3 栈）。
- **六权重**：target-only / Interleave 两种输出模式 × BF16 / FP8 / GGUF——GGUF 两版下载合计 8,438，端侧需求为主。
- **数字**：RealSI 长音频 StreamLAAL 约 **3 秒**（参评最低）；GEMBA 超 4/5 商用 API（打分 GPT6.1-Sol）；短音频四集 FLEURS 90.3 / CoVoST2 75.5 / ACL6060 81.2 / RealSI-Sentence 84.7（开源最高）；与 6 位 CATTI 译员对照 **3.3s vs 4.5/4.7s**。⚠️ 3 秒与 3.3 秒是两个不同集合；StreamLAAL ≠ 首次开口延迟。
- **部署三路**：vLLM ≥0.31（`HYV3ForCausalLM` + SimulInfer 一键脚本）覆盖全部 6 权重；llama.cpp 架构支持以 **PR #31198** 提交官方（未合并，先 `llama-mtmd-cli`）；SGLang-Omni 仅 BF16 target-only（单张 H200 约 57 GiB，比 Transformers 最高 6.5×）。另有 SimulTrain 继续训练工具与 Hy 翻译 App。

## 八、结论

本窗口最有参考价值的就两件事——**Hy4 正式版**（把发布模式从"开源日"切到"产品日"，agent 能力首次进旗舰：Computer Use + 视觉 + 幻觉率 7.2%；权重开源是下一个观察点）和 **FlashTopK/HyScale**（稀疏注意力从模型架构选择升级为"训练系统→内核"的全栈开源资产，同时服务 GLM/DeepSeek/Qwen 变体，是生态标准卡位）。次级但值得记录：Hy-SimulMT 补齐语音推理线（30B-A3B 模板复用）、双"程序化 ground truth"基准（HyperLogic/AppCIF）把"可验证"范式推到顶、Hy-Memory 进入高频产品化并首披生产数据。昇腾侧：本地商发分支已为 Hy4 day0 备好底座，权重开源后进入核对窗口；FlashTopK 内核思路与 Hy-SimulMT 负载形态按 P1 跟踪。
